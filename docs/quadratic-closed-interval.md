# 专题 01：二次函数闭区间恒成立

- 从登录后的首页或「功能与架构」进入[教师讲评](/topics/quadratic-closed-interval)，按知识 → 方法 → 原创例题 → 对照变式阅读。两题保留同一函数和区间，只把要求从上界换成下界；变式用反例说明只看端点为什么会漏掉区间内的最低点。
- [学生练习](/topics/quadratic-closed-interval/practice)先显示题干与可折叠的知识方法。草稿留在当前页面；点击「我已尝试，查看本题解析」后，登录且同源的 `POST /api/topics/quadratic-closed-interval/[item]/reveal` 只返回该题答案与解析。没有作答上报、学生评分或共享记录。
- 两页沿用受邀登录与本地回环模式。本次隔离的是页面和接口的数据，不新增师生账号角色；发给学生时使用练习链接。步骤批注属于教师页，不代表学生能力。
- 题包使用 `studio-topic-v1`，以专题内题 ID 和修订号定位题目；题目指回知识、方法、对照题及原创 MIT 来源。`npm test` 检查结构、引用与 KaTeX 渲染。这个题包不进入三题评分演示，也不用评分引擎给学生打分。
- 沪教版必修第一册第 5 章 5.2、5.3 为主，关联第 2 章 2.2。采用公开目录层级；实体书页码和原话待核。课堂使用前请任课教师独立复核；尚无课堂试用或学习效果证据。
