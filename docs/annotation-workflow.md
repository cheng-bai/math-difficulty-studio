# 教学批注工作流

批注帮助教师讲清「难在哪一步、学生可能错在哪里」。它不改变 H/C/T/D。评分口径见 [规则说明](scoring-rules.md)。

研究室已经有两处阅读面：题组阅读器里的「讲评重点」和「难度依据」，以及期中逐卷页的教师报告和逐步评分依据。本页规定批注写在哪、怎么写。不要另做一套旧式 Markdown 排版器。

## 写在哪里

| 内容 | 字段 | 读者在哪里看到 |
| --- | --- | --- |
| 整问讲评重点 | 题组 `content.teaching`；期中卷写在 `教师报告.md` | 题目与解析下方；期中教师阅读报告 |
| 紧贴某一步的批注 | 该步 `commentary` | 题组「难度依据」中该步下方；期中「查看逐步评分依据」表的「就地批注」列 |
| 入口与突破 | `B` 与 `B_evidence` | 分数条与 B 说明 |
| 找路与返工 | 五项 `risks` / `t` 与证据 | 「解题风险」或 T 依据 |

`commentary` 使用纯文本，公式放在 `$...$` 里。整问讲评和教师报告可以用 Markdown。没有批注就留空，阅读器不补空话。

期中教师报告仍是给教师通读的正文。逐步 `commentary` 只保留必须钉在该步旁边的句子，避免两处各写一篇。

## 先审题，再划步，再批注

1. 清点题号、小问、分值、选项和图形。缺图、题意冲突或无法核验的小问标为待核，写明 `issue`，不给确定的 D，也不把未知风险记成 0。
2. 有解析时核定义域、分类、等号和退化条件。能确认的错误写下原错误、修订和依据。不静默改题。
3. 主解法用步骤完整、符合题目范围的解法。备用解法单列，不因为篇幅短就替换主路径，也不把两条解法的工作量加在一起。
4. 一步对应一个有意义的中间结论。不为凑批注把移项拆开。前问已经允许引用的结论不重复计工作量。
5. 批注指向具体步骤。基础题可以只有一两句；中档和综合题说明入口、关键转换和边界。不是每题集齐全部标签。

程序复算只检查证据非空和依赖合法。数学是否正确、某一维为什么是 2，仍由审校者负责。

## 六个标签

只在相关时使用：

- 【入口】题干哪一个信号指向这个方法，为什么这时这样想。
- 【关键题素】从哪个条件跨到哪个结论。题素是可迁移的小单元，例如条件转译、构造对象、表征转换、分类边界。普通代入和重复运算不是题素。
- 【运算组织】消元、换元、配方或因式分解怎样安排，才能少算、少错。
- 【分类与边界】分类为什么必要，是否不重不漏，等号和退化情形如何处理。
- 【易错与检查】一个具体的错误动作，以及用代回、特值、范围或图形怎样发现它。
- 【教学追问】给学生一个逐步提示，不直接交出全部解法，并写明教师期待的关键回答。

每条通常两到四句，写清触发依据、数学动作和检查方法。不要只写「注意分类」或「体现转化思想」。

原创写法示例（用来看句子怎么落，不是待评分试题）：

> 任意两个不同元素的乘积为偶数，因此集合中至多有一个奇数。
>
> 【关键题素】两个奇数相乘仍是奇数，所以原条件排除了同时选入两个奇数。涉及所有数对的条件，转成对奇数个数的限制之后，计数按「不选奇数 / 只选一个奇数」分类。
>
> 【教学追问】已经选入一个奇数之后，其他元素还能再选奇数吗？期待学生用奇偶乘法说明限制，并检查只选偶数时原条件是否仍然成立。

工作室自带的原创演示第 2 题把同类批注写进了 `teaching` 和两个步骤的 `commentary`：先因式分解，再按含等号的二次不等式保留闭区间，并用端点代回检查。

## 交付前看一遍

- 每个批注能指回一个步骤或一个题面条件。
- 待核题没有被写成确定讲评结论。
- 必做分支和备用解法没有混在同一条路径里。
- 教师报告、逐步批注和评分证据没有互相矛盾。
- 公开仓库只保留原创或已获授权的表述。第三方试卷原文、官方解析原文和私人路径留在本地。
