# H/C/T/D 规则口径

权威实现是 [`modules/studio/scoring.py`](../modules/studio/scoring.py)，算法 `HCT-rules-v1.1`，引擎 `0.1.2`。本文只解释这份实现。输入的六维、依赖和风险由维护者提供，程序不解题，也不判断证据是否充分。

历史分数、手填的 H/C/T/D 和步骤上的 `s` 一律忽略，每次从步骤与 T 重算。

## 六维与步骤负荷

一个步骤是得到一个有意义中间结论的单位。阶段只组织方向，不重复计分。每步只取一个主要类型。可以引用的前问结论作为输入，不再把前问步骤算进本题工作量。

| 维度 | 0 | 1 | 2 |
| --- | --- | --- | --- |
| K 知识识别 | 题面直接对应公式、定义或定理 | 可指出的标准变式 | 未显露关系或非常规组合 |
| R 条件推理 | 单步直接推出 | 两三次常见转换 | 隐含条件、逆向构造或长依赖 |
| A 运算 | 一两步常规运算 | 中等化简或联立 | 长符号链、复杂含参或高错误敏感计算 |
| V 表征转换 | 不需要 | 一次文字、图像、公式或坐标转换 | 多次或双向转换 |
| P 参数与边界 | 无额外负担 | 单一参数、规则或边界 | 多分支、复杂量词或相互制约的边界 |
| I 知识交汇 | 单模块 | 两模块浅层配合 | 不同模块在同一关键推理中深度耦合 |

权重 K 0.20、R 0.25、A 0.15、V 0.15、P 0.15、I 0.10。每维取 0、1 或 2，并附该步实际数学动作。0 分也要说明为什么没有额外负担。

$$s_i=0.20K_i/2+0.25R_i/2+0.15A_i/2+0.15V_i/2+0.15P_i/2+0.10I_i/2.$$

类型 ID 与步骤实例 ID 分开。同名类型本身不触发重复折扣。可选用的起始类型见 [步骤类型参考词典](../content/reference/step-types.json)；期中包仍须自带词典，指纹不同会暂停相关难度比较。

## H、C、T、D 与 B

$$H=\operatorname{round}(100\max_i s_i).$$

在主解法的依赖图上，取有效负荷之和最大的一条根到终点路径。并列且负荷相同的路径按步骤 ID 的字典序取较小者，保证复算稳定。多条前置都是必要前置，但 C 不把并列分支相加。备用解法不要同时放进主路径。

路径上第 $j$ 步（从 0 起计）：

$$d_j=\min(1+0.1j,\ 1.3),\qquad e_j=s_j r_j d_j,\qquad E=\max\sum_j e_j.$$

只有写了同一个 `repeat_group` 且附有 `repeat_evidence` 时才折扣：该路径上同组第 1 次 \(r=1\)，第 2 次 \(0.7\)，第 3 次及以后 \(0.4\)。折扣按路径计数，不按全卷同名类型计数。

$$C=\operatorname{round}\left(100\left(1-\exp(-E/3)\right)\right).$$

T 的五项依次是：入口隐蔽、看似合理但无效的入口、错误发现延迟、回退范围、端点或等号或退化遗漏。每项 0、1 或 2，未知不能填 0。证据不足时把整问标为待核。

$$T=10\sum_{i=1}^{5}t_i,\qquad D=\operatorname{round}(0.45H+0.35C+0.20T).$$

档位：0—34 基础，35—64 中档，65—100 难题。先算分，再定档。

B 为 0—3，描述关键突破，不加入 D。必做分支数 `branches` 记录主解法里必须全部完成的终端情形；没有分类填 0，备用解法不算分支。

`review_flag` 在下面任一情况为真，并保留原 D：

- D 属于基础档且 B ≥ 2；
- 必做分支不少于 3。

这是复核提示，不是纠偏公式。

## 取整

只在标明 round 的位置做非负四舍五入（0.5 进 1）。中间的 s 与 e 用十进制权重和 40 位精度计算，不先截断再相加。

二进制浮点会把 \(100\times 0.575\) 表示成略小于 57.5。按错误的浮点值取整会得到 H=57；本引擎得到 H=58。单维 A=1 时 \(s=0.075\)，H=8，用来锁住另一处半分边界。这两项都有测试。

## 一则可复算的原创示例

两步，维度分别为 (1,1,1,0,0,0) 与 (1,1,0,0,0,0)，第二步依赖第一步，T 为 (0,0,0,0,1)，无重复组。

\(s_1=0.30\)，\(s_2=0.225\)，H=30。路径有效负荷 \(0.30+0.2475=0.5475\)，C=17，T=10，D=21，档位为基础。数字由引擎复算，见 `tests/test_scoring_rules.py`。

## 统计分母

`score_paper` 把传入列表视为一个分析单元。同一单元内题号必须唯一，不按年份把相同题号拆开。

有效均值、中位数、最高值和总体标准差只使用已定分小问，并同时给出有效数与总数。待核题的 D 为 null，不按 0 计入均值。六维画像先取每问各维的步骤峰值，再对已定分小问平均。

只有全部小问配分已知且全部定分时，才给出 `whole_paper_weighted_mean`。否则只给已标明分值且已定分子集的 `known_points_weighted_mean`。完整时的 `weighted_scope` 为「输入范围内分值已知且全部定分（未独立核验原卷清单）」。子集指标不能改称为整卷难度。缺配分不把大题分数均摊到小问。

依赖成环、重复 ID、缺失前置，或路径展开超过上限时直接失败。默认最多 100000 条路径。

## 复算入口

```sh
python3 scripts/score-evidence.py tests/fixtures/minimal-question.json --output /tmp/scored.json
```

单个小问对象只返回该问结果，不附整卷统计。含 `questions` 数组的文件按一个分析单元统计。`--output` 不能与输入是同一路径，避免覆盖证据。程序不写回输入文件。

期中正式明细仍按 [期中规范](midterms.md) 生成。题组维护仍走 ChangeSet，不能手填最终分数。

## 限制

权重和档位没有用真实作答数据校准。D 不是失分率，相差一两分不作实质难度判断。C 随划步粗细变化，也不代表全部必做分支的总工作量。证据是否站得住，由审校者负责。

教学批注的写法见 [批注工作流](annotation-workflow.md)。
